# 音樂調性分析器

## Proposal Report

### 動機與目標
<!-- 說明為什麼想做這個專題 -->
從小到大玩音樂的過程中，抓曲子及特定段落的調性都是很重要的部分，然而，調性屬於樂理的範疇，雖然可以透過學習來慢慢習得，但要是能透過程式幫忙抓調性，應該會是一個很方便的工具吧！ 

本專案的目標，就是寫出能夠讀取音訊檔，分析裡面各音高的強度，進而判斷其調性的工具。
### 預期功能
<!-- 列出預計實作的功能 -->
兼容各種市面上常見的音訊(eg. MP3, M4A, WAV)作為輸入，並且允許時間在一個區間內，約在一個小節到一整首5分鐘的歌曲。根據輸入的內容，判斷最可能的調性並輸出。

介面我預計用CLI在終端機上跑，不過若是有多餘的創作能量，我會嘗試升級成GUI。

### 使用技術
<!-- 使用的語言、框架、工具等 -->
本專案預計使用python實作，由於其搭載讀取音檔、時域轉頻域的相關函式等。 
針對專案功能的組成，我目前大致畫分成四個區間：
 
1.讀取&前置處理
 
架設環境並熟悉讀取所需的套件，我預計使用librosa裡面載入音檔，並做後續的處理 
 
2.核心特徵抓取
 
首先呼叫套件處理傅立葉轉換，才得以轉換成頻譜資料做使用，接下來需要過濾鼓聲及其他雜訊，並創作函式將音符的頻率範圍做資料分群，將這些音訊對應到十二個半音上，產出十二維度的能量矩陣。 
 
3.調性分析
 
建立總共24個大小調的權重樣板，並且將能量矩陣對其做相似度評比（這裡預計用內積來處理，抓取最相似的組成）
 
### 時程規劃
<!-- 各週預計完成的進度 -->
W1-W2: 讀取&前置處理、裁切區間，預計用時約15-20小時
 
W3-W5: 核心的特徵抓取實作，轉換成頻譜資料，並將髒資料轉換成乾淨資料，平滑處理後記錄在矩陣裡，大約要砸35-40小時
 
W6-W7: 調性分析，主要工程在建立調性樣板上，預計用時20小時
 
W8: 測試與除錯，進行大量資料的測試
 
### 與課程的關聯
<!-- 你的專題可能涉及哪些資料結構或演算法概念？為什麼？ -->
1.一維連續陣列：音檔解碼後，大約會需要百萬尺度的陣列儲存，如何利用連續性，精準抽出區間，避免遍歷以降低時間複雜度
 
2.快速傅立葉轉換： 一般來說離散轉換的運算量，大約在O(N^2)，但透過D&C能夠壓到O(NlogN)，極大的強化效率。
 
3.滑動視窗：特徵判別裡面需要每次抓一個區間（比如2048個取樣點），記錄頻率特徵，然後繼續向右滑動。

4.向量餘弦相似度應用： 透過此法與調性樣板做對比。
